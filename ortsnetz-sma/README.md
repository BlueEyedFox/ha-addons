# Home Assistant Add-on: Ortsnetz-Auslastung SMA

Empfängt die Messwerte eines SMA Sunny Home Manager 2.0 oder SMA Energy Meter im lokalen
Netz und sendet Phasenspannungen und Netzfrequenz alle fünf Minuten an
[ortsnetz-auslastung.de](https://www.ortsnetz-auslastung.de).

Basiert auf dem Script
[`sma-shm2-ortsnetz-auslastung`](https://github.com/thomaslehmann1234/datenerfassung-ortsnetz-auslastung/tree/master/sma-shm2-ortsnetz-auslastung).
Siehe Reiter **Dokumentation** für Einrichtung und Optionen.
