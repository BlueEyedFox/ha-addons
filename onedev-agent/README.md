# Home Assistant Add-on: OneDev Agent

Build-Agent für [OneDev](https://onedev.io): führt CI/CD-Jobs in Docker-Containern auf dem
Home-Assistant-Host aus.

Basiert auf dem offiziellen Image [`1dev/agent`](https://hub.docker.com/r/1dev/agent).
Siehe Reiter **Dokumentation** für Einrichtung und Optionen.
